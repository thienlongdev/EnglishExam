# Applied design decisions

The real ui-ux-pro-max skill was installed from nextlevelbuilder/ui-ux-pro-max-skill on 2026-11-02. Its design-system, Next.js, keyboard-focus and quick-reference workflows were run.

The verified `education examination focused editorial` result recommends Minimalism & Swiss Style, readable hierarchy and low-motion feedback. The broader education result targets children's claymorphism and is unsuitable for this university assessment product; it was not applied.

The generated MASTER.md is retained as historical research. The owner's 2026-11-02 continuation directive supersedes the earlier green/serif direction. Final product overrides: primary blue #2357b7, deep navy #183c76, ink #182b4b, muted #53647a, pale blue #eaf1fc, paper #f7f9fc, white surfaces. Quicksand Variable (Vietnamese/Latin, 300–700) is self-hosted throughout the app and the local OIDC theme. Semantic green/amber/red remain only for status. The existing editorial composition and illustration are preserved.

The current `university examination calm blue` skill search supported institutional navy and readable modular hierarchy; its portfolio pattern and serif pairing were not applied because they do not fit the existing exam product or the explicit Quicksand instruction. `error summary validation --domain ux` supported visible, announced feedback. No extra animation library was added. Route entry uses a short 280ms transition, dialogs 200ms, controls 160ms; reduced-motion disables all animation. React best-practices review retained independent fetches, cancellation cleanup, stable question keys, and server-side auth boundaries.

Controls use semantic HTML, visible focus and reduced-motion support. Native dialog supplies focus trapping and Escape. Answer controls are native radio inputs. Persisted answer count changes only after successful API confirmation. Timer is quiet to screen readers. All scoring comes from SQL Server.

Executed viewports: 375, 768, 1024 and 1440 CSS pixels; Chrome desktop emulation, keyboard navigation, reduced motion, error/loading/empty states, and all student/teacher routes. Mobile menu traps focus and dismisses with Escape; scrollable tables are keyboard focusable; labels and input patterns are validated in a real browser. 30 local axe reports have zero violations. Physical phones and other browser engines were not tested. See the final QA report for evidence.
